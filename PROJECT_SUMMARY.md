# 📊 Сводка проекта RAG Xakaton Final

## 🎯 Цель проекта

Создание RAG (Retrieval-Augmented Generation) системы для семантического поиска по банковским документам с использованием модели эмбеддингов FRIDA.

## 🏆 Лучшее решение

### Модель: FRIDA (ai-forever/FRIDA)
- **Размерность**: 1536
- **Максимальный контекст**: 512 токенов
- **Тип**: Sentence Transformer для русского языка

### Параметры чанков:
- **Размер**: 500 токенов (запас до лимита 512)
- **Overlap**: 100 токенов (~20% перекрытие)
- **Метод разбиения**: Умное разбиение по предложениям
- **Особенность**: Предложения не разрываются посередине

### Векторная БД: Qdrant
- **Метрика**: Cosine similarity
- **Порт**: 6883 (HTTP), 6884 (gRPC)
- **Docker**: qdrant/qdrant:v1.11.3

## 🔄 Пайплайн работы

### 1. Подготовка данных (prepare_chunks_frida.py)
**Вход**: `data/websites_cleaned.csv`  
**Выход**: `data/rag_collection/chunks_frida_500_100.json`

**Процесс**:
1. Загрузка токенизатора FRIDA
2. Чтение CSV с документами
3. Разбиение текстов на предложения
4. Группировка предложений в чанки до 500 токенов
5. Overlap на уровне предложений (100 токенов)
6. Финальная проверка: обрезка до 512 токенов
7. Сохранение в JSON

**Время**: ~5-10 минут

### 2. Создание эмбеддингов (ingest_frida.py)
**Вход**: `data/rag_collection/chunks_frida_500_100.json`  
**Выход**: Коллекция в Qdrant

**Процесс**:
1. Загрузка модели FRIDA на GPU/CPU
2. Создание/пересоздание коллекции в Qdrant
3. Для каждого чанка:
   - Добавление префикса `search_document:`
   - Создание эмбеддинга (1536-мерный вектор)
   - Загрузка в Qdrant с метаданными
4. Верификация коллекции

**Время**: ~30-60 минут (GPU) / 2-4 часа (CPU)

### 3. Поиск документов (rag_retrieval_frida.py)
**Вход**: `data/questions_clean.csv` + Коллекция Qdrant  
**Выход**: `submissions/submission_*.csv`

**Процесс**:
1. Загрузка модели FRIDA
2. Чтение вопросов из CSV
3. Для каждого вопроса:
   - Добавление префикса `search_query:`
   - Создание эмбеддинга вопроса
   - Поиск в Qdrant (top-50 чанков)
   - Агрегация по web_id (лучший score)
   - Выбор топ-5 web_id
4. Сохранение результатов в CSV

**Время**: ~2-5 минут

- **Qdrant коллекция**: ~2-3 GB

### Статистика чанков:
- **Количество**: ~10,000-15,000
- **Средний размер**: 400-500 токенов
- **Максимум**: 512 токенов (гарантированно)
- **Overlap**: 100 токенов между соседними

### Производительность:
- **Скорость чанкования**: ~1000 документов/мин
- **Скорость эмбеддингов**: 
  - GPU: ~5-10 чанков/сек
  - CPU: ~1-2 чанка/сек
- **Скорость поиска**: ~50-100 вопросов/сек

## 🎓 Ключевые особенности решения

### 1. Умное разбиение текста
✅ **Сохранение целостности предложений**
- Предложения никогда не разрываются посередине
- Грамотная обработка сокращений (т.е., т.д., руб.)
- Объединение слишком коротких предложений

✅ **Адаптивный overlap**
- Overlap на уровне предложений, а не токенов
- Сохранение контекста между чанками
- Оптимальное соотношение размер/overlap (80/20)

### 2. Жесткий контроль размеров
✅ **Многоуровневая проверка**
- Первичная проверка при группировке
- Вторичная проверка после создания чанка
- Финальная обрезка до MAX_TOKENS (512)
- Верификация после декодирования

✅ **Fallback механизмы**
- Разбиение длинных предложений по токенам
- Автоматическая обрезка при превышении лимита
- Защита от бесконечных циклов

### 3. Оптимизация памяти
✅ **Эффективная загрузка в Qdrant**
- Обработка по одному чанку (избегаем OOM)
- Батчи по 100 для загрузки в Qdrant
- Очистка GPU кэша после каждого чанка
- Graceful fallback на CPU

### 4. Корректная агрегация результатов
✅ **Умный поиск**
- Поиск 50 чанков (10x от top-k)
- Агрегация по web_id (лучший score)
- Гарантия 5 уникальных web_id
- Сортировка по релевантности

### 5. Правильное использование FRIDA
✅ **Префиксы**
- `search_document:` для документов при индексации
- `search_query:` для вопросов при поиске
- Нормализация эмбеддингов

## 🚀 Команды запуска

### Пошаговый запуск:
```bash
# 1. Запуск Qdrant
docker compose up -d qdrant

# 2. Активация окружения
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate     # Windows

# 3. Подготовка чанков
python -m src.prepare_chunks_frida --chunk-size 500 --overlap 100 --output chunks_frida_500_100.json

# 4. Создание эмбеддингов
python -m src.ingest_frida --input chunks_frida_500_100.json --collection bank_site_frida_500_100

# 5. Поиск
python -m src.rag_retrieval_frida --collection bank_site_frida_500_100
```
