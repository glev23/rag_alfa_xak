# 📁 Папка данных

В эту папку необходимо поместить исходные данные для работы RAG системы.

## Необходимые файлы

### 1. `websites_cleaned.csv`
Очищенные веб-страницы банковских документов.

**Формат:**
```csv
web_id,url,kind,title,text
1,https://example.com,article,Заголовок,Текст документа...
```

**Колонки:**
- `web_id` - уникальный ID документа (int)
- `url` - URL страницы (str)
- `kind` - тип документа (str)
- `title` - заголовок страницы (str)
- `text` - текст документа (str)

### 2. `questions_clean.csv`
Вопросы для поиска ответов.

**Формат:**
```csv
q_id,query
1,Какой минимальный платеж по кредитной карте?
```

**Колонки:**
- `q_id` - уникальный ID вопроса (int)
- `query` - текст вопроса (str)

## Создаваемые файлы

### `rag_collection/`
В эту подпапку будут сохраняться JSON файлы с чанками после обработки:
- `chunks_frida_500_100.json` - чанки размером 500 токенов с overlap 100

## Размер файлов

Примерный размер файлов:
- `websites_cleaned.csv`: ~50-100 MB
- `questions_clean.csv`: ~1 MB
- `rag_collection/*.json`: ~100-200 MB
